PARTIE SSM KALMAN STATIONNAIRE (Section 2.1)
- state_space_builders.py:

	- PeriodicSSM: dataclass qui stock ce qui def le SSM (dimensions, matrices d’état, matrices d’observation périodiques, liste de noms des observables selon la sous-période pour debug)

	- _block_diag(*blocks): fonction privée pour construire les covariances de zeta = (eta_t, eps_t) => Q = blockdiag(cov_eta, diag(sigma_eps_2))

	- build_mixedfreq_dynamic_factor_ar1_me(...): builder principal qui “instancie” le modèle du papier en le traduisant en matrices Kalman. Def état alpha (empilation des facteurs et leurs retards + erreurs de mesure AR(1) (pour l'instant on fait le cas théorique opti, une fois que vérif okay on fait cas erreurs AR(k)). Def transition G: L’état contient p blocs de facteurs : bloc 0 = F_t; bloc 1 = F_t-1/m; ...; bloc p-1 = F_t-(p-1)/m. Qd on passe de t-1/m à t, le nouveau F_t dep des anciens blocs et les blocs sont décalés => F_t-1/m devient le bloc 1, etc (La première ligne du state (le nouveau facteur) est une combinaison linéaire des anciens blocs de facteurs.); def innovations & covariance de zeta Q; def mesure Zj
pour l'instant il fait pas y pour les variables flow


- steady_state_riccati.py: calcule le steady-state périodique : une suite périodique P_1|0,...,Pm|m-1, les gains Kj associés, les matrices Sj => dans le papier = filtre de Kalman périodique en régime stationnaire, utilisé pour écrire les prévisions comme sommes pondérées de x et de y.

	- PeriodicSteadyState: dataclass correcteur pour stocker la solution périodique stationnaire du filtre de Kalman (P_j|j-1, K_j, S_j, A_j)

	- _sym(A): fonciton privée pour forcer les mat de covariance à être symétriques (A + A')/2 -> A

	- solve_periodic_steady_state: Trouver une suite périodique {P_1|0, P_2|1, ..., P_m|m-1} telle que après un cycle complet on retombe sur la même suite (itération pour trouver la convergence = équivalent résolution (2.8) en périodique: 2.8 revient à faire Pupdate + Pprediction => permet d'écrire le filtre comme une somme infinie de poids). Après CV, calcul final de Kj, Sj, Aj. inputs: G mat de transition, Q_tilde covariance RQR', Z_list, tol et max_iter critères de convergence, jitter diag ajoutée à S pour éviter singularité

	- riccati_step(P, Z): calcule Sj = Zj.Pj|j-1.Z'j; Kj = PZ'S^-1; Pj|j = (I- KZ).P (update)


- kalman_periodic.py:

	- KalmanFilterOutput: dataclass conteneur pour stocker les résultats de filtrage à chaque pas; x_pred[t] = alpha_hat_t|t-1 = état prévu avant d'utiliser l'observation du pas t; x_filt[t] = alpha_hat_t|t = état filtré après la mise à jour avec l'observation du pas t; P_pred[t] = cov prédite; P_filt[t] = cov màj; innov[t] = y_t - Z_j.alpha_hat_t|t-1 = innovation; S[t] = cov de l'innovation

	- kalman_filter_periodic(...): inputs: y_seq = liste des observations à chaque pas HF (longueur = nombre total de pas (par ex. T*m); dimension variable : doit correspondre à Z_list[j].shape[0] au pas t); G= matrice de transition de l’état; Q_tilde = covariance du bruit d’état (dans l’espace de l’état) (en pratique : Q_tilde = R @ Q @ R.T); Z_list = liste [Z_1, ..., Z_m] matrices d’observation périodiques; x0, P0 = conditions initiales; steady_state = si fourni, on utilise les gains périodiques constants K[j] et S[j]. on a ici 2 cas: steady-state ; time-varying (pour section 3.4/ 4)
